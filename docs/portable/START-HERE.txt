GITGUI 0.1.0 — Windows x64 免安裝版

1. 將整個 ZIP 解壓縮至有寫入權限的資料夾。
2. 開啟 GITGUI.vbs。不要直接在壓縮檔內啟動。
3. 使用「瀏覽」開啟 Git 倉庫，或使用「倉庫操作」建立／複製倉庫。
   已有檔案但尚未初始化：在「倉庫操作」瀏覽原資料夾，首次使用填寫姓名／Email，
   按「初始化倉庫」，再檢查檔案、按「全部暫存」、輸入訊息並「提交」。
   原檔案與 .gitignore 會保留；姓名／Email 僅儲存於此倉庫，初始化不會上傳 GitHub。
4. 「外觀配色」提供石墨深色、午夜藍、森林綠與霧白，選取後立即套用並記住。
5. 「進階功能」提供 stash、互動式 rebase、cherry-pick/revert/reset、標籤、reflog、遠端管理、檔案歷史與 Blame。
6. 進行中的 rebase/cherry-pick/revert 可在重新啟動後繼續、略過或中止；先在主畫面解決並暫存衝突。
7. 「終端機」使用目前倉庫與所選 Git 的持續文字 shell；先關閉終端機再由 GUI 寫入。
   不支援 VT 全螢幕與 Ctrl+C；關閉會結束 shell 子程序。任意終端機指令不保證自動快照復原。

完整操作手冊：用瀏覽器開啟與 GitGui.App.exe 同一層的 USER-GUIDE.zh-TW.html。
另附可編輯的 USER-GUIDE.zh-TW.md。
手冊包含 M1 日常操作、M2 進階歷史、M3 倉庫工具、M4 快捷鍵與診斷、快照復原與常見問題；可離線閱讀。
新手請從第 20 章「第一次備份」與第 21 章「修改後更新上傳」開始；
兩章附 16 張真實操作截圖、編號框選與逐步說明，圖片可點擊放大。
請一起保留 images/walkthrough 資料夾，離線閱讀才會顯示全部圖片。

內附 .NET 10.0.13 與完整 Portable Git 2.56.0.3，不需另外安裝。
請一起保留 PortableGit 資料夾及其他 DLL；整個資料夾可移動。
「Git 設定」預設自動偵測程式旁 PortableGit。若曾選過其他 Git，
請按「自動偵測」後儲存，以使用內附版本。

支援 Windows x64；具體 Windows 版本限制見操作手冊與 docs/M4-ACCEPTANCE.md。
不需要系統管理員權限，不修改系統 PATH。
本版 GITGUI 執行檔未做 Authenticode 簽章。
v0.7.1 完成 504 項 Windows 本機回歸與免安裝解壓／啟動檢查。
M4 正式效能數據對應 v0.7.0 的受測版本，原門檻未調整，詳見 docs/M4-PERFORMANCE.md。
預設啟動需要 Windows 內建 Windows Script Host；若環境不允許 VBS，
可改用 GitGui.App.exe。1.5 秒冷啟動驗收使用 GITGUI.vbs，備用方式時間可能不同。
請保留 GitGui.Host.dll、GitGui.App.r2r.dll 及所有隨附檔案。

此處「免安裝」指執行環境隨附；使用者設定、信任清單、最近倉庫、
快照索引及生命週期日誌仍存於 %LOCALAPPDATA%\GitGui。
Git 使用個人的 Git 設定、憑證與 SSH keys；首次 commit 需設定作者。
不會內附帳號、密碼或私人金鑰。

移除程式：關閉後刪除解壓縮資料夾即可。刪除程式不會刪除 Git 倉庫。
更新：解壓縮新版本至新資料夾再啟動，勿覆寫正在執行的程式。
