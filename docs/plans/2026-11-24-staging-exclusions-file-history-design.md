# 暫存排除修正與檔案歷程

範圍：本機實作與驗證，未發布 Release；沿用既有工作目錄，保留使用者的 `graphify-out/`。

- 排除問題：重新整理期間的選取暫存先決定操作，後續載入的新規則沒有重新套用。先保留選取檔案，等讀取完成後重新過濾；不自動取消使用者既有暫存。
- 歷程入口：工作區按鈕直接開啟既有進階歷程分頁；無變更的檔案可用原生檔案選擇器選取，限制目前專案內路徑。沿用現有讀取介面及引擎，不新增服務或套件。

- 驗證：排除時序失敗回歸、501 筆歷程、重新命名、未提交專案、舊結果丟棄、主視窗入口與中英文介面；完整 Core／UI／Engine 測試及獨立真實 Git 桌面操作。
