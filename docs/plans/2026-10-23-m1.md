## 安全界線

不使用 libgit2 寫入。所有 Git index/refs/objects 寫入透過 CLI。快照內容以無 filter 的 Git blob 保存原始位元組，還原由 git cat-file 物件輸出落盤，避免 CRLF／filter 重轉換；不直接編輯 index 或 refs 檔。忽略檔不在 clean 範圍，碰到 checkout/restore 路徑碰撞先拒絕操作。P2 的 submodule、sparse 與其他無法安全擷取的狀態採明確前置檢查，不冒險覆寫。

## UI 方向

使用深色石墨背景、單一藍色操作重點、獨立的新增／刪除色、12–14px 緊湊資訊層級、系統 UI/CJK 字型與等寬程式碼字型。保留可調欄寬、清楚選取／焦點及原始 Git 輸出。UI/UX 搜尋的落地頁版型不適用本桌面工具，不採用；沿用符合開發工具的配色與鍵盤指引。
