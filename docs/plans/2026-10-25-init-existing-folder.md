# 在 GUI 初始化已有檔案的資料夾

本機修改與測試；不推送、不建立 GitHub 倉庫、不發布 Release。

初始化接受一般非空目錄，以 Git 建立 `.git`，保留工作檔案及既有 `.gitignore`。Clone 保持要求空目錄。已存在 `.git`（含檔案或連結）、父倉庫或 bare repository 時拒絕初始化，避免重新設定既有倉庫。

沿用「倉庫操作 → 初始化倉庫」視窗，加入瀏覽資料夾、操作說明，以及可選的提交者姓名與電子郵件。兩欄填寫後僅儲存在此倉庫的 local config；都留空則沿用既有 Git 身分設定。不自動暫存或提交。初始化完成沿用主視窗的自動開啟與刷新，使用者檢查檔案後按「全部暫存」與「提交」。

驗收：真實 Git 整合測試確認非空目錄初始化、中文／二進位檔內容不變、忽略檔不進入提交、第一筆提交成功且沒有遠端；驗證既有倉庫／gitfile／父倉庫／bare 及 Clone 保護。實際 Avalonia 視窗與後端串接測試驗證按鈕、身分設定與暫存／提交流程，以及取消不寫入。最後執行本機完整 Core、Engine、UI 測試與 Windows 建置。
