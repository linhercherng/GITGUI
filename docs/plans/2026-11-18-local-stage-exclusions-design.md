# 本機暫存排除清單

使用者已選擇每個專案各自保存的本機排除清單，適用已追蹤與未追蹤檔案；不寫入 `.gitignore`。

## 行為與資料

- 精確檔案路徑、資料夾及其後代可加入清單；檔案仍顯示於工作區並可檢視差異。
- 選取暫存、全部暫存、區塊暫存及標記衝突已解決會遵守排除規則；重新命名須檢查新舊路徑。
- 規則不刪除檔案、不自動取消既有暫存，也不改變提交、合併或快照復原。介面提示符合規則的已暫存內容仍會提交。
- 規則保存在既有本機 SQLite 設定資料庫的新表格，依 canonical repository root 隔離；交易保存，無效規則或讀取失敗不允許誤暫存。
- 使用相對路徑、字面比對及資料夾分隔邊界；拒絕絕對路徑、NUL、空路徑成分、`.` 與 `..`，保留合法檔名空白與 Unicode。

## 介面

工作區增加「暫存排除清單」按鈕，管理視窗沿用既有佈景、圖示與視窗樣式。可加入目前選取檔案、選擇檔案、選擇資料夾、移除規則；按儲存才套用。新增規則後顯示目前符合排除的工作區與已暫存數量。

## 實作與驗證

1. 先以測試驗證檔案、資料夾邊界、重複／巢狀規則、重新命名、特殊檔名及非法路徑，再實作純比對模型。
2. 實作 SQLite 儲存；驗證跨專案隔離、重啟載入、交易與無效輸入不覆蓋原資料。
3. 串接暫存動作與設定載入，保留刷新期間的排隊暫存；驗證全部排除時不執行 Git，也不影響取消暫存。
4. 加入管理視窗、中英文及圖示，以實際控制項與整合測試檢查範圍、保存及錯誤處理。
5. 更新操作手冊，完成完整測試與 CI；原 M4 失敗紀錄及門檻保留，全部正式關卡通過後才發布免安裝版。
