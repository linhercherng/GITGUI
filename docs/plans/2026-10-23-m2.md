Shared contracts first. Isolated changes: snapshot files, advanced UI files and
terminal files are delegated; root owns contracts, WorkspaceService, readers,
integration and release. All writes remain Git CLI with one repository queue.
Unsupported P2 repository modes remain guarded. Terminal commands are explicitly
user-driven and cannot promise automatic undo of arbitrary external commands.
