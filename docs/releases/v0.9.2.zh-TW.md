# GITGUI v0.9.2 — 暫存排除修正與檔案歷程

Windows x64 免安裝功能更新，內附完整 Portable Git 2.56.0.windows.3、Git LFS、SSH 及 .NET 10.0.13。完整解壓後執行 `GITGUI.exe`，請保留整個資料夾。

## 更新內容

- 修正背景重新整理期間「暫存選取」沿用舊排除規則的問題。保留點選的檔案，等待讀取完成後以最新規則重新過濾；全部被排除時不執行 Git 暫存。
- 新增工作區「檔案歷程」入口及原生檔案選擇器，沒有未提交變更的檔案也能直接選擇。
- 顯示目前分支 HEAD 可追溯的完整檔案提交歷程，包含 Git 能辨識的重新命名，不再截斷為 500 筆；Git CLI 改為批次讀取提交資訊與路徑。
- 選取任一歷程提交，可查看該次與第一個父提交的差異，重新命名前的版本使用當時路徑。切換選取或關閉視窗時取消舊查詢，防止過期結果覆蓋目前內容。
- 修正首次開啟進階視窗時，初始化讀取導致自動載入歷程被略過的問題。
- 更新繁體中文離線手冊，保留 24 章、57 張標示截圖；第 4.2 節提供排除清單完整圖例，第 7.1 節說明新檔案歷程操作。

## 使用提醒

新增排除規則不會自動取消既有暫存。請先在「已暫存」選取該檔並取消暫存，再按「全部暫存」核對結果；檔案仍會留在工作區。規則只存於這台電腦的 GITGUI 設定，不改寫 `.gitignore`，不隨提交上傳。

檔案歷程查詢目前 HEAD 的歷史，不包含其他尚未合併分支獨有的提交或未提交內容；逐行來源分頁維持顯示目前 HEAD。此查詢不會切換分支或還原工作檔。

## 驗證與效能範圍

本版沿用使用者接受延遲的功能版發布方式，以完整本機功能測試、同提交六格 CI、精確 ZIP 的功能與桌面驗證作為發布條件。原始 TRX、套件雜湊與各項結果見 `verification.json` 及驗證證據附件。

**M4 正式效能仍未通過，原門檻沒有修改。** v0.9.1 候選包曾在驗收電腦記錄約 26～29 秒啟動等待及捲動空檔超標，原因仍待確認；這些數據不是 v0.9.2 的驗收成績。本版未重新執行完整 M4 正式效能量測，也不以功能啟動探針宣稱通過。啟動時請等待主視窗出現，避免連續重複開啟。

本版執行檔未提供程式碼簽章。請核對 `SHA256SUMS.txt`；主程式、獨立離線手冊、驗證證據及第三方 copyleft 對應來源一併提供。免安裝包不包含使用者的設定資料庫、帳號、憑證或金鑰。
